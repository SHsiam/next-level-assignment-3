Library Management API is a RESTful service built with Express, Vercel, TypeScript, and MongoDB that allows users to manage books and borrowing records. 
It supports book creation, updates, filtering, borrowing with availability checks, and provides summary reports using MongoDB aggregation.

The Library Management API provides endpoints to manage books and borrowing records in a library system.

Add, retrieve, update, and delete book records

Filter and sort book listings by genre, date, etc.

Borrow books with validation of available copies

Automatically update book availability based on stock

Retrieve a summary report of all borrowed books using aggregation
